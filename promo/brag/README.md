# Промо-ролик терминала

Ролик собирается браузером: `vertical.html` (1080x1920, под телефон) и
`index.html` (1920x1080) - это композиция, где каждый кадр целиком вычисляется
функцией `seek(t)`. CSS-анимаций нет специально: покадровый рендер не зависит
от того, успел ли браузер отрисовать анимацию вовремя.

Картинки берутся с лендинга и в репозитории не дублируются.

## Сборка

```bash
node sync-assets.mjs                                  # забрать картинки и шрифты из webapp
PAGE=vertical.html W=1080 H=1920 node render.mjs      # 9:16, результат vertical.mp4
PAGE=index.html    W=1920 H=1080 node render.mjs      # 16:9, результат index.mp4
```

Проверить отдельные кадры без полного рендера:

```bash
PAGE=vertical.html node preview.mjs 1.5 6.4 10.6 13.6 17.4 20.5
```

Нужен ffmpeg на PATH и Chromium из `webapp/node_modules` (ставится вместе с Playwright).

Добавить музыку к готовому рендеру:

```bash
node render.mjs --music path/to/track.mp3
```
